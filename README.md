# SLA Breach Analysis & Prediction

This project focuses on analyzing SLA breaches and building a machine learning model to predict potential SLA violations.

## Key Highlights
- SLA Breach Rate: ~6.5%
- Total Incidents: 138K+
- Built predictive model with 79% accuracy
- Identified key drivers like assignment group & risk category

## Tools Used
- Python (Pandas, Scikit-learn)
- Power BI
- SQL
